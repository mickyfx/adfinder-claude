# AdFinder: Competitor Ads

By Storez LLC. Research competitor advertising inside Claude and Claude Code using your existing AdFinder account.

## What you can do

- Find ads in available Meta, TikTok, Google and LinkedIn ad libraries.
- Compare competitors’ messages, offers and creative formats, with original source links.
- Browse returned ads and each ad’s creatives with separate controls in supported chat viewers.
- Research public posts on X/Twitter and Reddit, public profiles and available transcripts. Organic posts are identified separately from advertisements.
- Check your shared AdFinder credits without running paid research.

Try “Show me how to use AdFinder,” “Find Nike ads in the United States,” or “Compare two competitors’ ad hooks within 5 credits.” Available filters depend on the selected search. AdFinder quotes a bounded research plan before paid requests; installation alone does not spend credits.

## Install and connect

In Claude, install the plugin and connect AdFinder in its Connectors tab. In Claude Code, use the supported plugin installation and MCP authentication flow. Sign in through the AdFinder authorization page. Never paste a password or token into chat. No additional data-service account or API key is required.

Your regular AdFinder balance is shared across connected products. A mobile review bonus, when present, is shown separately and is not available for plugin research. Connecting another assistant does not grant additional free credits. Local mobile Collections are not synchronized by this plugin.

## Results and media

Search results distinguish observed information from the assistant’s interpretation. Unavailable fields and unverified advertising performance are never filled in. Completed results can be redisplayed for free. One viewer contains the saved ads with separate navigation between ads and their creatives. Images and video playback depend on the host and original media availability; original links remain useful when playback is unavailable.

The seven bundled Skills cover getting started, competitor ads, creative references, content and profiles, transcripts, budgeted research, and account help. Their usage rules are in [TOOL-CONTRACT.md](TOOL-CONTRACT.md).
